01 / References

Project JSON ≤ 32 MB; 256 glyphs; 24 styles; 8,000 commands per glyph; 40 undo steps / 64 MB history. Your own or authorized artwork only. PNG/JPEG/SVG: 8 MB; images ≤ 4096 × 4096; 24 references; SVG ≤ 8,000 commands. SVG external content is rejected.

Correction → trace/draw → confirm → analyze. A trace is an editable proposal, never proof of fidelity.

Width 0 preserves crop proportions; a chosen width explicitly changes them. Correction output ≤ 1200 × 700.

02 / Construction rules

Capture a whole reconstructed shape or selected contour. Edit missing strokes, bowls, arches, serifs and accents directly. Starter components are original drawings, awaiting your approval.

03 / Extend & propagate

Preview changes before applying. Approved, locked and manually edited outlines are preserved. Generation never approves a glyph.

04 / Family development

Light / Bold are editable proposals. Approve representative extremes before interpolating. Italic requires independent structural decisions; Oblique is a separate shear operation.

05 / Export

Static outlines. Edits require re-export. Open contours must be closed before font export.

Inspection / capabilities
No stock font outlines. Automatic analysis measures bounds, candidate stem runs and slant; it cannot determine serif intent, optical quality or unseen anatomy. Complex organic, stencil and experimental designs need user-drawn components or independent glyphs. No automatic skeleton extraction or recognition.
