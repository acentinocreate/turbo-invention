# Publication assets

- `icon.svg`: independently drawn application icon, no font/art dependency.
- `publication-card.svg`: original 1200 × 630 vector card. Typography uses the viewer's system monospace family; no external font assets. H/partial bowl artwork is an original path drawing.
- `desktop.png`, `mobile.png`: actual Chromium screenshots of the application and candidate proof.

Publish `index.html` to any static host. Supporting documentation may be published alongside it. No deployment has been performed. Keep embedded full licence notices when distributing only the HTML.
